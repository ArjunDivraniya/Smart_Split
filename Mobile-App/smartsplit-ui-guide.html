05 — Motion
Animations & Micro-interactions
Every interaction should feel alive. These animations guide users and create delight without distraction.
💸
Float
Splash logo, empty state icons, onboarding illustrations
Pulse Ring
Notification badge, settle button, new expense indicator
Bounce
Loading dots, success confirmation, tab press feedback
Spinner
API loading states, saving expense, confirming payment
Slide
Screen transitions, swipe to delete, bottom drawer open
₹0
counting up
Count Up
Dashboard balance reveal, analytics totals, settle confirm
Progress Fill
Budget bars animating in on screen load
Stagger Fade Up
List items appear on screen mount, expense feed load
Animation Rules for React Native
Duration
Micro: 150ms · Standard: 300ms · Transitions: 400ms · Page loads: 600ms
Easing
Ease.out for entrances · Ease.in for exits · Spring for interactive gestures
Library
react-native-reanimated for gestures · Animated API for simple transitions
Rule
Haptic feedback on settle & confirm · Never animate layout during scroll
